一个纯静态的销售运营数据看板 Demo，包含「当月看板」与「历史看板」两大视图，用于展示数据看板的交互与信息组织方式。

## 功能概览

**当月看板**

- 大区 / 单元 Tab 切换，六张汇总卡（人数、大定总量、人均大定、人均工作量分、人均试驾量、人均有效通话）
- 单元综合评价：自动生成的「优势 / 问题 / 建议」
- 开单分布三饼图（按岗位级别）、车型大定分布（柱 + 环）、工作量综合分析（柱 + 雷达）
- 门店详情：下拉切换门店，门店 vs 单元对比
- 大定龙虎榜 / 工作量龙虎榜：搜索、排名徽章、表现标记（💎🟢🟡🔴 四分位）

**历史看板**

- 1–12 月多选对比、大区 / 单元 / 门店三级查看范围
- 月度汇总卡 + 四张对比图（大定量、车系占比、工作量、人均效率双轴）

## 技术形态

- 纯静态单页 `index.html`：样式、逻辑、数据全部内嵌，无后端、无数据库、无任何外部网络请求
- 图表：Chart.js 4.4.0 + chartjs-plugin-datalabels（本地化，不走 CDN）
- Excel 导入：SheetJS（xlsx.full.min.js，本地化）
- 部署：任意静态托管即可，本仓库直接使用 GitHub Pages

```
index.html                        # 主页面（含内嵌演示数据）
assets/chart.umd.min.js           # Chart.js
assets/chartjs-plugin-datalabels.min.js
assets/xlsx.full.min.js           # 「导入新数据」用
.nojekyll                         # 关闭 GitHub Pages 的 Jekyll 处理
```
